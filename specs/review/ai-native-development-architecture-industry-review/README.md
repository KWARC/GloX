# Industry review archive (optional)

Periodic external benchmarks of your **documented** SDD approach. Each run is a dated Markdown file
in this directory. Findings are **not operational policy** until a human accepts them.

**Companion:** implementation review at repo root under `specs/review/` (create when you adopt periodic
audits).

## Layout

```
ai-native-development-architecture-industry-review/
  ├── README.md           ← this file
  └── YYYY-MM-DD.md       ← one file per review run (ISO date)
```

Newest file by date is the latest run. Keep prior files — do not overwrite.
